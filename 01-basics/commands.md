# 🐙 Git Basics

## 1. Check Git Version

```bash
git --version

Purpose: Check whether Git is installed and see its version.

2. Configure Git Username
git config --global user.name "Your Name"

Purpose: Set the username used for Git commits.

Check username
git config --global user.name
3. Configure Git Email
git config --global user.email "your@email.com"

Purpose: Set the email address used for Git commits.

Check email
git config --global user.email
4. Initialize a Repository
git init

Purpose: Create a new Git repository in the current folder.

5. Check Repository Status
git status

Purpose: Check the current state of the Git repository.
