# Git Basics

### git --version
Check the installed Git version.

### git config --global user.name "Your Name"
Set the username associated with your Git commits.

### git config --global user.email "your@email.com"
Set the email address associated with your Git commits.

### git config --global user.name
Check the configured Git username.

### git config --global user.email
Check the configured Git email.

### git init
Initialize a new Git repository in the current folder.

### git status
Check the current state of the Git repository.
