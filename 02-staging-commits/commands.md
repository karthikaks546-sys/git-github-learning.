# Staging & Commits

### git add <filename>
Add a specific file to the staging area.

### git add .
Add all changed and untracked files to the staging area.

### git commit -m "message"
Save the staged changes as a commit with a message.

### git log
View the commit history of the repository.

### git log --oneline
View the commit history in a short, one-line format.

### git show <commit-hash>
View the details and changes of a specific commit.
