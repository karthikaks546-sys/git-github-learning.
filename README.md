# 🐙 Git & GitHub Learning

A hands-on repository to learn, practice, and document **Git and GitHub**.

This repository is not just a collection of commands.  
The goal is to understand **what each command does, when to use it, and how it works in a real project**.

---

## 🎯 Goals

- Learn Git from the basics
- Understand the Git workflow
- Practice Git commands hands-on
- Learn branching and merging
- Understand GitHub and remote repositories
- Practice collaboration workflows
- Learn how to handle common Git mistakes
- Build a quick reference for future projects

---

## 📚 Topics

| # | Topic | What I'll Learn |
|---|---|---|
| 01 | Git Basics | Installation, configuration, repository creation |
| 02 | Staging & Commits | `add`, `commit`, `log`, and Git workflow |
| 03 | Branches | Creating, switching, merging and deleting branches |
| 04 | GitHub & Remote | `remote`, `push`, `pull`, `fetch`, `clone` |
| 05 | Undoing Changes | `restore`, `reset`, `revert`, `stash` |
| 06 | Collaboration | Forks, upstream, pull requests |
| 07 | Practice | Hands-on Git exercises |
| 08 | Mistakes & Lessons | Errors I faced and how I solved them |
